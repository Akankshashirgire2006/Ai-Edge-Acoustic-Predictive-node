 AI-Edge Acoustic Predictive Maintenance Node

An AI-Based Approach to Motor Condition Monitoring Using Acoustic Signals

📌 Project Overview

The AI-Edge Acoustic Predictive Maintenance Node is a machine learning-based prototype that explores motor condition monitoring through acoustic signals. It aims to identify unusual patterns in motor sounds and investigate how machine learning can support the detection of potential motor abnormalities.

The project combines audio recording, signal processing, machine learning, and embedded hardware. Currently, machine learning inference runs on a laptop, while the ESP32 is used for hardware communication and integration experiments.

🎯 Project Objectives

- Record and analyze motor sound signals.
- Preprocess audio data for machine learning.
- Extract useful features from acoustic signals.
- Train and test a machine learning model.
- Integrate the ESP32 with the project setup.
- Explore future deployment using Edge AI and TinyML.

⚙️ Project Workflow

1. Audio Acquisition: Record motor sounds using a microphone.
2. Audio Preprocessing: Prepare audio samples for analysis.
3. Feature Extraction: Extract relevant characteristics from audio signals.
4. Model Training: Train a machine learning model using the prepared dataset.
5. Prediction Testing: Test the model using available audio samples.
6. Hardware Integration: Connect and test the ESP32 with the project setup.
7. Future Deployment: Investigate running a suitable lightweight model on embedded hardware.

🛠️ Technologies Used

🚧 Current Limitations

- Machine learning inference currently runs on a laptop rather than directly on the ESP32.
- Prediction reliability depends on the quality and diversity of the audio dataset.
- Background noise and microphone placement may affect predictions.
- Additional testing with different motors and operating conditions is required.
- The prototype has not been validated for industrial predictive maintenance.

🔮 Future Improvements
